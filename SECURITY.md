# Security and privacy

The scanner runs with the current user's permissions, reads system statistics, and writes local reports. It does not upload data, install services, request administrator privileges, or quit processes. The browser dashboard has no native execution bridge.

Reports can contain executable paths, process names, and sleep assertion descriptions. Do not post complete personal reports in public issues. Process command-line arguments and raw network addresses are outside exported data. The public demo is synthetic.

If you find a vulnerability, use GitHub's private vulnerability reporting for this repository when enabled. If it is unavailable, open an issue asking for a private contact method without posting sensitive details. Do not include credentials or personal diagnostics.

The latest release is the supported version. There is no promised response-time SLA. Fixes affecting parsing, HTML embedding, CSV exports, report permissions, or distribution should include a regression test.
