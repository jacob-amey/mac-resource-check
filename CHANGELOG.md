# Changelog

## 2.1.0 — 2026-10-01

- Split source and generated launchers with reproducible builds and version checks.
- Added a public synthetic-data demo and dashboard layout illustration.
- Refined colors, spacing, navigation copy, dialog labeling, and keyboard access.
- Added per-report-folder collector locking and `--version`.
- Fixed watch shutdown so its idle timer stops with the collector.
- Kept missing I/O counters unavailable instead of treating them as zero.
- Added portable parser/dashboard checks and macOS launcher integration tests.
- Added CI, draft releases, checksums, release notes, and contribution templates.
- Added usage, measurement, privacy, architecture, and publishing documentation.

## 2.0.0 — 2026-10-01

- Added scan history, baseline comparisons, process inspection, pins, and custom thresholds.
- Added network/disk rates, active swap, average/peak CPU, and in-sample trends.
- Added automatic browser launch, a repeated-scan launcher, filtered exports, and themes.

## 1.0.0 — 2026-09-30

- Initial local scanner with app grouping, CPU/memory/power views, suggestions, and offline reports.
