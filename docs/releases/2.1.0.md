# Mac Resource Check 2.1.0

A local macOS scanner with an offline dashboard, process inspection, and scan comparisons.

Download `mac-resource-check-2.1.0.zip`, unzip it, and double-click **Mac Resource Check.command**. The report opens in your browser after a roughly 12-second sample. Use **Live Monitor.command** for scans every 30 seconds; stop with Control-C in Terminal.

This release adds a cleaner interface, a synthetic-data demo, versioned source/build tooling, per-folder scan locking, automated checks, and release checksums. The scanner retains app grouping, average/peak CPU, memory and I/O context, sleep assertions, custom review thresholds, exports, and bounded history.

Requires macOS; no extra runtime installs or administrator password. Live collection has been checked on macOS 27 on Apple silicon. macOS 12+ and Intel support are intended but not fully verified. Power is a CPU-and-wakeup proxy rather than watts. Reports remain local and may contain private process context.

Verify the download from the folder containing both release files:

```bash
shasum -a 256 -c mac-resource-check-2.1.0.zip.sha256
```

Browser layout and additional compatibility checks are documented in the release checklist. Review those checks before publishing this draft.
